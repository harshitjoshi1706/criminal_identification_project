# Face and Gait Biometric Recognition

A computer vision project focused on identifying individuals using **face and gait biometrics**.

## About the Project

The goal of this project is to develop a biometric recognition system that uses facial features and walking patterns (gait) for person identification.

The project will explore how recognition performance is affected by real-world conditions such as:

* Blur
* Occlusion
* Low image resolution
* Poor face quality

The system will eventually combine information from both **face recognition** and **gait recognition** to improve identification accuracy.
